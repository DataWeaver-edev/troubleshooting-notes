# troubleshooting-notes

软件 / 驱动 / 系统类问题的排查记录。每条都是**实测过的完整链路**，不是搜来的结论摘录。

## 为什么写这个

排查这类问题最贵的不是修，是**定位**。同一个坑在不同机器上表现相似但根因不同，
网上能搜到的答案又多是「重装驱动」「重启试试」。这些记录按固定结构写，
目的是让人和 agent **按症状关键词就能搜到可复现的根因与解法**。

## 记录结构

```
环境 → 现象 → 复现步骤 → 根因（附注册表 / 日志 / 截图证据） → 解决方案 → 已排除的无效方向 → 中文摘要
```

每条记录同时保留中英双语，标题里放症状关键词。
